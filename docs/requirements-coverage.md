## 3 选做扩展

| 选做项 | 状态 | 说明 |
|---|---|---|
| 匿名模式 | 已完成 | AI 默认以 `user_id = NULL` 写入，不关联具体学生 |
| 聚合模式 | 已具备聚合展示 | 看板和多维统计只展示汇总分布与趋势；尚无独立“仅保留聚合、不保存明细”存储开关 |
| 消息队列异步 AI | 扩展项 | AI 服务采用带重试的 REST 入库 |
| MCP 工具服务 | 扩展项 | 预留为智能体接入方向 |
| Docker Compose | 已完成 | 后端、AI 服务和数据卷配置齐全 |
| CI 流水线 | 已完成 | GitHub Actions 自动运行静态检查、16 项 Node 测试和 6 项 AI 测试 |

系统扩展到多实例或高并发部署时，可增加 Redis/RabbitMQ 消息队列；接入智能体时，可将查询统计能力封装为 MCP 工具。
