# 5 至 8 分钟演示脚本

## 0:00 至 0:40 项目介绍

说明系统解决的问题、四类参与者和数据闭环。展示 README 和总体架构图。

## 0:40 至 1:40 管理员准备课堂

1. 使用 admin 登录。
2. 展示用户管理和三种角色。
3. 创建一门演示课程并指定 teacher。
4. 创建当前时间附近的课堂。
5. 选择 student 保存排课名单。

讲解后端会校验教师、时间范围和学生身份，名单可以替换或清空。

## 1:40 至 2:40 学生提交

1. 使用无痕窗口登录 student。
2. 确认能看到刚创建的课堂。
3. 连续提交开心、困惑等表情。
4. 打开个人历史，说明学生只能看到本人数据。

## 2:40 至 3:50 教师实时看板

1. 使用 teacher 登录并打开对应课堂。
2. 展示样本量、主导情绪、需关注反馈和最新动态。
3. 学生再提交一次表情。
4. 观察教师页面自动刷新。
5. 展示最近 15 分钟趋势折线图。

说明 Socket.IO 只向有权课堂房间广播。

## 3:50 至 4:50 AI 集成

1. 打开 AI Swagger 或执行 `/simulate`。
2. 提交置信度 0.92 的 AI 记录。
3. 在教师看板或管理员数据页确认来源 AI、匿名和置信度。
4. 提交低于阈值的结果，展示其未入库。
5. 简要展示摄像头接口和不保存原始图像的设计。

## 4:50 至 5:50 多维统计和导出

1. 管理员按课程、班级和时间范围筛选。
2. 展示分布、课堂样本量和趋势图。
3. 导出当前筛选范围 CSV。
4. 用文本编辑器或 Excel 打开，说明 UTF-8 BOM 和 CSV 注入防护。

## 5:50 至 6:50 安全、接口与测试

1. 打开 `/api/docs` 展示 Swagger。
2. 运行 `npm test`，展示 12 项通过。
3. 运行 `npm run test:ai`，展示 9 项通过。
4. 简述 bcrypt、JWT、RBAC、参数化 SQL、AI 独立令牌和审计日志。

## 6:50 至 7:30 总结

说明系统实现了从需求、设计、开发、AI 集成到测试部署的闭环，同时明确 AI 情绪识别只能作为整体趋势辅助，不能用于个体评价。

## 录制前准备

- 清理无关浏览器标签和终端输出。
- 同时准备管理员、教师、学生三个浏览器会话。
- 确保课堂时间覆盖演示时间。
- 预先启动后端和 AI 服务。
- 检查摄像头权限和网络。
- 准备失败时的 `/simulate` 备用方案。
