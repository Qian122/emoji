# 需求规格说明书

## 1 项目目标与范围

系统采集学生主动提交或 AI 视频推理产生的课堂情绪记录，为学生提供个人历史，为教师提供本人课堂的实时看板、趋势和统计，为管理员提供用户、课程、课堂、排课、全局统计和安全导出能力。

系统用于课堂整体趋势辅助，不把面部表情等同于真实心理状态，不用于个体评价或高风险自动决策。默认不保存原始视频和人脸图像。

## 2 角色与权限

| 角色 | 核心权限 | 数据边界 |
|---|---|---|
| 学生 | 注册、登录、改密、提交 emoji、查看个人历史 | 只能提交已排课课堂，只能查看本人记录 |
| 教师 | 注册、登录、改密、查看课堂历史、实时看板和多维统计 | 只能访问本人所授课程 |
| 管理员 | 用户启停、课程课堂管理、排课、全局统计、CSV 导出 | 可以访问业务全局，但不能停用当前账号 |
| AI 服务 | 提交匿名化推理结果 | 仅能使用独立服务令牌调用 AI 入库接口 |

## 3 主要用例

| 编号 | 用例 | 参与者 | 前置条件 | 成功结果 |
|---|---|---|---|---|

| UC03 | 提交课堂情绪 | 学生 | 已被安排到课堂 | 记录以 MANUAL 来源入库并广播事件 |

| UC05 | 查看教学看板 | 教师 | 课堂属于该教师 | 显示最近 15 分钟统计、趋势和最新动态 |
| UC06 | 管理用户状态 | 管理员 | 已登录 | 用户被启用或停用，当前管理员不可自停用 |

## 4 功能需求

### 4.1 认证与用户

- 用户名为 3 至 30 位中英文、数字、下划线或连字符。
- 密码至少 8 位，必须包含大小写字母和数字。
- 密码使用 bcrypt 加盐哈希，禁止明文存储。
- 登录成功签发有有效期的 JWT；账号停用后已有令牌立即失效。
- 管理员注册需要独立注册码。

### 4.2 课程课堂与排课

- 管理员创建课程并指定有效教师。
- 管理员创建具有开始时间、结束时间、教室和班级的课堂会话。
- 结束时间必须晚于开始时间。
- 排课名单只允许包含有效学生账号，保存操作完整替换旧名单并支持清空。
- 学生、教师、管理员查询课堂时按角色自动裁剪范围。

### 4.3 情绪记录

- 支持 HAPPY、CALM、CONFUSED、SAD、ANGRY、SURPRISED 六类枚举。
- 手动记录包含学生、课堂、时间、来源和设备标识。
- AI 记录包含课堂、时间、来源、置信度和设备标识，默认匿名。
- 学生不能向未安排课堂提交记录。

### 4.4 实时看板与统计

- 教师看板显示最近 15 分钟样本量、主导情绪、需关注反馈、AI 样本、分布、时间趋势和最新动态。
- Socket.IO 按 `session:{id}` 隔离课堂房间，教师只能加入本人课堂。
- 多维统计支持课程、班级、开始时间和结束时间组合筛选。
- 统计同时返回情绪分布、课堂样本量和按分钟趋势。

### 4.5 导出

- 管理员导出与当前统计筛选条件一致的 CSV。
- 文件为 UTF-8 并带 BOM，便于 Excel 正确显示中文。
- 以 `= + - @` 开头的单元格增加单引号，防止 CSV 公式注入。
- 导出操作写入审计日志。

### 4.6 AI 服务

- 支持摄像头采样、上传帧分析和模拟结果三种验证路径。
- DeepFace 结果映射为六类 emoji，支持多脸结果。
- 置信度阈值和采样间隔可通过环境变量配置。
- 后端失败最多重试三次并记录日志。
- 未安装视觉模型时，服务仍可启动 `/health` 和 `/simulate`，摄像头接口返回明确的 503 提示。

## 5 非功能需求

| 类别 | 要求 | 实现或验证 |
|---|---|---|
| 安全 | JWT、RBAC、课堂归属、AI 独立令牌、输入校验、认证限流 | 后端中间件和自动化测试 |
| 隐私 | AI 默认匿名，不保存原始视频和人脸 | 数据模型与 AI 内存处理 |
| 可用性 | 响应式中文 Web 页面、错误提示、演示数据 | `public/` 和种子数据 |
| 性能 | 统计字段建立索引，单次历史查询最多 500 条 | SQLite 索引与查询上限 |
| 可维护性 | 修改版 MVC、统一 API 契约、集中配置 | `server/`、`public/`、OpenAPI |
| 可部署性 | 本机启动和 Docker Compose 两种方式 | README、Dockerfile、部署说明 |
| 可测试性 | Node 集成测试、Socket.IO 测试、AI 单元测试、人工 E2E 清单、CI 流水线 | `tests/`、`ai-service/test_main.py`、`.github/workflows/ci.yml` |

## 6 验收标准

完整验收项目和证据位置见 [验收检查表](acceptance-checklist.md)。所有核心业务项必须通过；摄像头识别受硬件和模型环境影响，至少应完成模拟 AI 全链路，并在有摄像头的设备完成一次现场测试。

## 7 系统边界与外部依赖

### 7.1 系统边界

系统负责用户认证、角色授权、课程和课堂会话管理、学生名单安排、情绪记录、实时推送、统计、导出以及 AI 推理结果接收。系统不负责学校统一身份认证、学生成绩管理、考勤认定、纪律处理或心理健康诊断。

### 7.2 外部依赖

| 依赖 | 用途 | 不可用时的降级策略 |
|---|---|---|
| 浏览器 | 学生、教师、管理员操作界面 | REST API 仍可通过 Swagger 验证 |
| 摄像头 | AI 视频帧采集 | 使用 `/simulate` 验证 AI 入库链路 |
| OpenCV | 摄像头读取和图像帧处理 | AI 服务继续提供健康检查和模拟接口 |
| DeepFace | 人脸检测与情绪分类 | 摄像头接口返回 503，不影响其他系统功能 |
| SQLite | 业务数据持久化 | 后端无法正常工作，应阻止启动并检查路径权限 |
| Docker Desktop | 容器化部署 | 使用 Node/Python 本机双进程部署 |

### 7.3 假设与约束

- 一次课堂会话只属于一个课程，课程只指定一名负责教师。
- 学生必须先进入课堂排课名单，才能向该课堂提交手动 emoji。
- AI 记录默认匿名，不尝试识别或绑定具体学生身份。
- 时间统一以 ISO 8601 字符串存储，展示时由浏览器转换为本地时间。
- 当前数据库和实时通信面向课程实验及单机部署，不承诺大规模并发能力。

## 8 详细功能需求编号

### 8.1 认证与用户管理

| 编号 | 需求描述 | 优先级 | 验收条件 |
|---|---|---:|---|
| FR-AUTH-01 | 学生和教师可以使用用户名、邮箱和密码注册 | 必须 | 合法输入返回 201，重复用户名或邮箱返回 409 |
| FR-AUTH-02 | 管理员注册必须提供正确的独立注册码 | 必须 | 错误注册码返回 403，正确注册码可完成注册 |
| FR-AUTH-03 | 用户可以使用用户名和密码登录 | 必须 | 正确凭据返回 JWT；错误凭据返回 401 |
| FR-AUTH-04 | 登录用户可以验证当前密码后修改密码 | 必须 | 修改后旧密码失效，新密码可登录 |
| FR-AUTH-05 | 密码不得明文保存 | 必须 | 数据库仅存在 bcrypt 哈希，成本因子为 12 |
| FR-AUTH-06 | 管理员可以启用或停用用户 | 必须 | 停用后旧 JWT 立即失效；管理员不能停用自己 |
| FR-AUTH-07 | 所有受保护接口必须校验 JWT 和角色 | 必须 | 未认证返回 401，角色不符返回 403 |

### 8.2 课程、课堂与排课

| 编号 | 需求描述 | 优先级 | 验收条件 |
|---|---|---:|---|
| FR-CLS-01 | 管理员可以创建课程并指定有效教师 | 必须 | 非教师或停用教师不能被指定 |
| FR-CLS-02 | 管理员可以创建课堂会话 | 必须 | 保存课程、起止时间、教室和班级 |
| FR-CLS-03 | 课堂结束时间必须晚于开始时间 | 必须 | 时间范围错误返回 400 |
| FR-CLS-04 | 管理员可以查询、替换和清空课堂学生名单 | 必须 | 保存结果与提交列表完全一致 |
| FR-CLS-05 | 排课名单只能包含有效学生 | 必须 | 教师、管理员、无效 ID 或停用学生被拒绝 |
| FR-CLS-06 | 课堂查询按角色裁剪 | 必须 | 学生只见已排课课堂，教师只见本人课程，管理员可见全部 |

### 8.3 Emoji 记录

| 编号 | 需求描述 | 优先级 | 验收条件 |
|---|---|---:|---|
| FR-EMOJI-01 | 学生可以选择六类 emoji 提交课堂反馈 | 必须 | 合法提交返回 201 并写入 MANUAL 记录 |
| FR-EMOJI-02 | 学生不能向未排课课堂提交 | 必须 | 越权提交返回 403 |
| FR-EMOJI-03 | 学生可以查看个人历史 | 必须 | 返回记录均属于当前学生 |
| FR-EMOJI-04 | 教师可以查看本人课堂历史及学生用户名 | 必须 | 不返回其他教师课堂记录 |
| FR-EMOJI-05 | 管理员可以查看全局 emoji 数据 | 必须 | 同时显示 MANUAL、AI、时间、课堂和设备来源 |

### 8.4 看板、统计与导出

| 编号 | 需求描述 | 优先级 | 验收条件 |
|---|---|---:|---|
| FR-DASH-01 | 教师可查看当前课堂最近 15 分钟实时汇总 | 必须 | 显示样本量、主导情绪、需关注反馈和 AI 样本 |
| FR-DASH-02 | 新记录写入后看板自动刷新 | 必须 | 对应课堂房间收到 `emoji:new` 事件 |
| FR-DASH-03 | 教师和管理员可查看情绪分布与趋势 | 必须 | 返回六类分布和分钟趋势数据 |
| FR-DASH-04 | 多维统计支持课程、班级、开始和结束时间组合筛选 | 必须 | 组合条件只影响目标数据范围 |
| FR-DASH-05 | 管理员可导出与当前筛选一致的 CSV | 必须 | UTF-8 BOM、中文正常、危险前缀已转义 |

### 8.5 AI 推理集成

| 编号 | 需求描述 | 优先级 | 验收条件 |
|---|---|---:|---|
| FR-AI-01 | AI 服务可从摄像头按间隔采样帧 | 必须 | 启动后按配置间隔执行分析，停止后释放摄像头 |
| FR-AI-02 | AI 服务使用 DeepFace 完成人脸检测和情绪分类 | 必须 | 有视觉依赖时返回情绪及置信度 |
| FR-AI-03 | 模型情绪映射为系统六类 emoji | 必须 | happy 等模型标签被稳定映射到枚举值 |
| FR-AI-04 | 低于阈值的结果不得入库 | 必须 | 返回 LOW_CONFIDENCE，数据库无新增记录 |
| FR-AI-05 | AI 记录标记来源、置信度和设备，默认匿名 | 必须 | `source=AI`、`user_id=NULL`、置信度存在 |
| FR-AI-06 | 默认不保存原始视频或人脸图像 | 必须 | 程序只进行内存帧处理，不存在保存路径 |
| FR-AI-07 | AI 后端调用失败时自动重试 | 必须 | 最多重试三次并输出错误日志 |

## 9 非功能需求的量化标准

| 编号 | 类别 | 量化标准或检查方式 |
|---|---|---|
| NFR-SEC-01 | 安全 | 密码强度、bcrypt、JWT、RBAC、参数化 SQL 和输入校验全部通过自动测试或代码审查 |
| NFR-SEC-02 | 会话 | 停用账号的既有 JWT 在下一次请求立即失效 |
| NFR-PRI-01 | 隐私 | AI 默认匿名；源码和数据目录中没有原始帧持久化逻辑 |
| NFR-PERF-01 | 性能 | 历史查询单次最多 500 条；高频查询字段建立索引 |
| NFR-REL-01 | 可靠性 | AI 提交失败最多重试三次；服务健康接口可独立检查 |
| NFR-USA-01 | 易用性 | 常用操作不超过三级导航，失败时显示中文错误信息 |
| NFR-MNT-01 | 可维护性 | 前端、业务路由、数据库、实时通信和 AI 服务分目录组织 |
| NFR-DEP-01 | 可部署性 | 支持本机启动和 Docker Compose 两种部署方式 |
| NFR-TST-01 | 可测试性 | 静态检查、14 项 Node 测试和 5 项 AI 测试可由 CI 自动执行 |

## 10 数据需求

| 数据对象 | 关键字段 | 保存目的 | 保留与隐私原则 |
|---|---|---|---|
| 用户 | 用户名、密码哈希、角色、邮箱、状态 | 认证与授权 | 不保存明文密码 |
| 课程 | 名称、教师 | 教学关系 | 仅管理员维护 |
| 课堂会话 | 课程、班级、教室、起止时间 | 排课和统计范围 | 结束时间必须晚于开始时间 |
| 排课名单 | 课堂、学生 | 控制学生访问 | 仅保存必要关联关系 |
| Emoji 记录 | 课堂、类型、来源、时间、置信度 | 历史、统计和看板 | AI 默认匿名，不保存人脸 |
| 审计日志 | 操作者、动作、详情、IP、时间 | 安全追踪 | 不记录密码、JWT 或图像内容 |

## 12 不在本次必做范围的扩展

- Redis/RabbitMQ 消息队列异步处理 AI 结果。
- MCP Server 形式的智能体工具服务。
- 多租户、学校统一身份认证和细粒度组织架构。
- 只保留聚合结果、完全不保存情绪明细的独立存储模式。
- PostgreSQL 集群、多实例 Socket.IO 和生产级监控告警。

以上项目属于选做或生产化扩展，不影响第 2.1、2.2 必做功能验收。
