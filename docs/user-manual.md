# 用户手册

## 1 访问系统

后端启动后访问 `http://localhost:3000`。演示账号：

| 角色 | 用户名 | 密码 |
|---|---|---|
| 学生 | student | Student123! |
| 教师 | teacher | Teacher123! |
| 管理员 | admin | Admin123! |

正式部署必须更换默认密钥和演示密码。

### 1.1 注册与登录

1. 在登录页切换到注册表单。
2. 输入 3-30 位用户名、有效邮箱和至少 8 位且包含大小写字母与数字的密码。
3. 选择学生或教师角色后直接注册；选择管理员时还需输入部署环境中的管理员注册码。
4. 注册成功后系统签发登录令牌并进入对应角色页面。
5. 已有账号直接输入用户名和密码登录。账号被停用或密码错误时页面显示错误原因。

管理员注册码来自服务端 `ADMIN_REGISTRATION_CODE`，只用于创建管理员账号，不应提供给普通用户。注册教师后，其账号需要由管理员在创建课程时选择，教师才能看到所授课堂。

### 1.2 修改密码与退出

所有角色均可进入“账号设置”，输入当前密码和符合复杂度要求的新密码。修改成功后使用新密码登录。退出操作会清除浏览器保存的 JWT；账号被管理员停用时，已有 JWT 也会立即失效。

## 2 学生操作

1. 登录后进入“情绪打卡”。
2. 在课堂下拉框选择已安排课堂。
3. 点击开心、平静、困惑、难过、生气或惊讶。
4. 提示“已记录”后，统计和最近反馈自动更新。
5. 在“我的历史”按课堂查看本人记录。
6. 在“账号设置”输入当前密码和符合复杂度要求的新密码完成修改。

学生看不到其他学生记录，也不能向未排课课堂提交。

## 3 教师操作

1. 进入“教学看板”，选择本人授课课堂。
2. 查看最近 15 分钟样本量、主导情绪、需关注反馈和 AI 样本。
3. 查看情绪占比、最新动态和按分钟趋势折线图。
4. 保持页面打开时，新记录通过 Socket.IO 自动触发刷新。
5. 在“课堂记录”查看本人课堂历史。
6. 在“统计分析”按课程、班级和时间段筛选分布、趋势和课堂样本量。
7. 在“AI 摄像头”选择本人课堂，按第 5 节执行预览和分析。

教师不能选择或查询其他教师课程。

## 4 管理员操作

### 4.1 用户管理

- 查看用户名、邮箱、角色、状态和注册时间。
- 停用账号后，其已有令牌立即失效。
- 管理员不能停用当前正在使用的账号。
- 新管理员通过注册页选择 ADMIN 并提供正确管理员注册码创建；普通管理员登录后不能查看其他用户密码哈希。

管理员可在“实时看板”选择任意课堂，查看与教师端一致的最近 15 分钟统计、最新动态和趋势图。

### 4.2 课程课堂与排课

1. 创建课程并选择有效教师。
2. 创建课堂会话，填写开始时间、结束时间、班级和教室。
3. 在排课区域选择课堂，系统自动回显当前名单。
4. 多选学生后点击保存，名单将完整替换。
5. 取消全部选择后保存可以清空排课。

### 4.3 统计与导出

1. 选择课程和班级。
2. 可选填写开始和结束时间。
3. 点击“应用筛选”查看该范围内的分布、趋势和课堂样本量。
4. 点击“导出筛选结果”，CSV 内容与当前筛选一致。
5. 点击“重置”恢复全局统计。

## 5 AI 服务操作

AI 服务启动后访问 `http://localhost:8000/docs`。

### 5.1 模拟验证

在无摄像头或未安装 DeepFace 时调用 `/simulate`。只要 FastAPI、Pydantic 和 HTTPX 可用，服务即可启动；`/health` 的 `visionAvailable` 会说明视觉依赖状态。

### 5.2 摄像头验证

安装完整依赖后，教师或管理员打开侧边栏“AI 摄像头”，选择课堂并点击“打开摄像头预览”。页面会实时显示镜像画面，便于调整面部位置、角度和光照。系统优先使用 OpenCV 快速检测，未发现人脸时会放大画面并切换 MTCNN 高灵敏度检测器，同时扩展人脸边缘区域。单次操作最多自动采集 3 个画面寻找有效人脸，但每个有效画面均独立进行单帧判断，不做概率融合。

- “检测当前画面”执行一次人脸和情绪分析；
- “开始连续检测”每约 3 秒采样一次；
- 页面显示检测次数、入库数量、过滤数量、情绪和置信度；
- 当前帧未检测到人脸时，单次操作会自动采集下一帧重试，最多 3 次；
- 低于统一置信度阈值的单帧结果会被过滤，不写入数据库；
- “停止并释放”或离开页面会关闭浏览器视频轨道；
- 超过阈值的结果匿名写入数据库，原始画面不保存。

无浏览器界面的部署仍可调用 `/camera/start` 和 `/camera/stop` 完成后台采样。

### 5.3 常见问题

| 现象 | 处理 |
|---|---|
| 401 AI_TOKEN_INVALID | 确认 AI 与后端使用相同 `AI_SERVICE_TOKEN` |
| 502 后端暂不可用 | 先启动 3000 端口后端并检查 `AI_BACKEND_URL` |
| 503 OpenCV 尚未安装 | 安装 `ai-service/requirements.txt` 或先使用 `/simulate` |
| 摄像头启动后无记录 | 查看终端日志、摄像头编号、光照、阈值和 DeepFace 模型 |
| Web 页面无预览 | 在浏览器地址栏允许摄像头权限，并检查物理隐私挡板 |
| 画面正常但持续无人脸 | 面部尽量正对镜头并占较大区域，避免强逆光；确认 AI 服务已重启并启用 `opencv,mtcnn` |
| 多次重试仍无人脸 | 保持正面、改善光照并让面部占画面较大区域，检查物理隐私挡板 |
| 识别结果与主观感受不同 | 以学生主动反馈和教学情境为准，不把单帧 AI 标签当作事实 |

## 6 API 与故障排查

- Web 健康检查：`http://localhost:3000/api/health`
- Swagger：`http://localhost:3000/api/docs`
- OpenAPI JSON：`http://localhost:3000/api/openapi.json`
- AI 健康检查：`http://localhost:8000/health`

端口占用时先停止旧进程，或者修改 `.env` 中的 `PORT`。数据库异常时检查 `DB_PATH` 指向目录是否可写。

## 7 完整业务操作流程

### 7.1 新课堂准备

1. 管理员进入用户管理，确认教师和学生账号处于启用状态。
2. 创建课程并选择负责教师。
3. 创建具体课堂，填写班级、教室、开始时间和结束时间。
4. 打开该课堂的学生名单，勾选参加课堂的学生并保存。
5. 使用学生账号重新登录，确认课堂出现在可选列表。

### 7.2 上课期间

1. 教师提前打开实时看板并选择当前课堂。
2. 学生根据课堂理解情况选择 emoji。
3. 如启用 AI，管理员或技术人员启动 AI 服务和摄像头任务。
4. 教师观察样本量、主导情绪、需关注反馈和趋势，不根据单个样本评价学生。
5. 若困惑、难过或生气比例持续升高，教师结合课堂提问、练习结果等信息人工判断是否调整教学节奏。

### 7.3 课后

1. 教师查看该课堂完整历史和基础统计。
2. 管理员按课程、班级和时间段生成多维统计。
3. 如需留档，管理员在相同筛选条件下导出 CSV。
4. 管理员定期检查账号状态、审计日志和数据库备份。

## 8 页面数据含义

| 指标 | 含义 | 使用注意 |
|---|---|---|
| 总样本量 | 时间范围内手动和 AI 记录总数 | 同一学生可提交多次，不代表人数 |
| 主导情绪 | 样本数最多的 emoji 类型 | 只反映记录分布，不代表班级真实心理状态 |
| 需关注反馈 | CONFUSED、SAD、ANGRY 的合计 | 应结合教学情境人工解释 |
| AI 样本 | 来源为 AI 的记录数 | 受摄像头、阈值和模型偏差影响 |
| 分布 | 六类 emoji 的数量及占比 | 样本少时比例波动较大 |
| 趋势 | 按分钟聚合的变化 | 用于观察课堂过程变化，不用于个体判断 |

## 9 权限和隐私说明

- 学生不能查看其他学生记录。
- 教师只能查看本人所授课堂。
- 管理员具有业务全局权限，应限制管理员账号数量并保护注册码。
- AI 默认匿名，不把面部结果绑定到学生账号。
- 系统默认不保存摄像头原始视频或人脸图像。
- 面部表情分析可能误判，禁止将结果用于成绩、纪律处分或心理诊断。

## 10 角色功能速查

| 操作 | 学生 | 教师 | 管理员 |
|---|---:|---:|---:|
| 注册、登录、改密 | 是 | 是 | 是，注册需管理员码 |
| 查看可访问课堂 | 已排课课堂 | 本人授课课堂 | 全部课堂 |
| 手动发送 emoji | 是 | 否 | 否 |
| 查看历史 | 本人 | 本人课堂 | 全部 |
| 实时看板与多维统计 | 否 | 本人课堂 | 全部 |
| 用户、课程、课堂和排课管理 | 否 | 否 | 是 |
| CSV 导出 | 否 | 否 | 是 |
| Web 摄像头 AI | 否 | 本人课堂 | 全部课堂 |

## 11 安全使用建议

- 首次部署立即修改默认演示密码和密钥。
- 不要通过聊天软件发送 JWT、AI 令牌或 `.env`。
- 公共电脑使用后退出账号并关闭浏览器。
- 导出的 CSV 可能包含用户和课堂信息，应放在受控位置。
- 停用离校或不再参与项目的账号。
- 使用摄像头前完成师生告知与授权。
